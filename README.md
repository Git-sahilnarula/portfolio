# Sahil — Portfolio (React + Vite + Tailwind CSS)

Personal portfolio of **Sahil** (Final-Year BCA student at Chandigarh Group of Colleges, Landran, Mohali — 8.09 CGPA), showcasing Data Analytics, Power BI Dashboards, AI & n8n Workflow Automation, and Full-Stack Web Development.

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server (http://localhost:5173)
npm run dev

# Build for production (Netlify / Vercel)
npm run build
```

## Project Structure

- [`src/data/portfolioData.js`](src/data/portfolioData.js) — Central configuration file containing personal info, summary, skills, featured projects, experience, education, and certifications.
- [`src/components/`](src/components/) — Modular React components (`Navbar`, `Hero`, `About`, `Skills`, `Projects`, `Education`, `Certifications`, `Contact`, `Footer`).
- [`public/`](public/) — Static assets, certificates, resume PDF, and `linkedin-profile.json` skills/certifications directory.
- [`legacy/index.html`](legacy/index.html) — Exact 1:1 backup of the original single-file portfolio.
